# SmartRepair — Booking System

Інформаційна система для онлайн бронювання послуг ремонту.

## Структура проекту
- **/client**: Фронтенд на React.
- **/server**: Бекенд на Node.js (Express + Sequelize).
- **init.sql**: Скрипт ініціалізації бази даних з початковими даними.
- **docker-compose.yml**: Конфігурація для розгортання у Docker-контейнерах.

## Технології
- **Stack**: MySQL, Node.js, React.
- **Hardware**: ESP32, DHT11 sensor.

## Інструкція із запуску

Для забезпечення стабільної роботи застосунку з використанням фіксованих версій ПЗ, розгортання виконується за допомогою Docker.

Після клонування репозиторію, виконайте наступну команду в кореневій директорії проєкту:

```bash
docker-compose up --build
```
Ця команда автоматично виконує наступні дії:

1. Створює та запускає контейнер із базою даних MySQL.
2. Виконує ініціалізацію схеми даних та наповнює її тестовими записами через файл `init.sql`.
3. Збирає та запускає серверну частину (Node.js/Sequelize).
4. Збирає та запускає клієнтську частину (React/Vite).

Після успішного завершення процесу застосунок буде доступний за адресою: `http://localhost:5173`
