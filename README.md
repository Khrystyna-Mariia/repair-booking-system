# SmartRepair — Booking System

Інформаційна система для онлайн бронювання послуг ремонту.

## Структура проекту
- **/client**: Фронтенд на React.
- **/server**: Бекенд на Node.js (Express + Sequelize).

## Технології
- **Stack**: MySQL, Node.js, React.
- **Hardware**: ESP32, DHT11 sensor.

## Як запустити
1. Налаштуйте базу даних у `server/.env`.
2. У папці `server`: `npm install` та `node index.js`.
3. У папці `client`: `npm install` та `npm run dev`.
